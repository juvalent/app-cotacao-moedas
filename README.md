# 💸 Cotação de Moedas

Aplicativo mobile desenvolvido com React Native que consome uma API pública de câmbio para exibir a cotação atual do dólar em diferentes moedas.

---

## 🚀 Tecnologias utilizadas

- React Native
- JavaScript
- Hooks (`useState` e `useEffect`)
- Fetch API
- ExchangeRate API

---

## 📱 Funcionalidades

- Consulta em tempo real da cotação do dólar
- Conversão para:
  - Real (BRL)
  - Euro (EUR)
- Interface simples e moderna
- Consumo de API utilizando `fetch`

---

## 🔗 API utilizada

[ExchangeRate API](https://www.exchangerate-api.com/)

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/juvalent/app-cotacao-moedas.git
```

Entre na pasta:

```bash
cd app-cotacao-moedas
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npx expo start
```
